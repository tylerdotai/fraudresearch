# Official program guidance

No reward eligibility or payout rate is guaranteed by this toolkit. Retrieve and preserve your own current written source before a consequential program-fit assessment.

- Public portal: https://america.gov/fraud
- DOJ overview: https://www.justice.gov/fraud/whistleblower
- Detailed pilot terms: https://www.justice.gov/fraud/national-fraud-enforcement-division-criminal-tip-rewards-pilot-program
- FAQ: https://www.justice.gov/fraud/criminal-tip-rewards-pilot-program-faqs
- Prior-publication context: https://www.whitehouse.gov/fraud/

`fraudlab refresh-rules` acquires new private snapshots. Acquisition is not legal interpretation or a filing. Check exact current scope, original information, voluntary disclosure, eligibility exclusions, required criminal milestone, discretion, anonymity and confidentiality clauses. Keep conflicting announcements and operative wording distinct until reconciled by competent authority.

Independent public-data analysis can be relevant without making every public anomaly original qualifying information. Repeating a published audit/enforcement case is not an original discovery. Public searches cannot establish what the government already knows confidentially.

Any submission requires a separate human decision with exact identity, destination, content and attachments. The repository has no automatic reporting command and is not an intake channel.
