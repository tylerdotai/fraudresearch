# Falsification matrix

| Inference at risk | Strong alternative | Decisive check | Failure disposition |
|---|---|---|---|
| Same name means same recipient | Namesake/DBA/branch/date change | Namespace IDs and dated original records | Candidate/unresolved identity |
| Shared address means concealed ownership | Mail service, campus, agent, landlord | Address purpose plus ownership/control evidence | Address cluster only |
| Duplicate record means duplicate payment | Snapshot/measure/adjustment repetition | Record grain, payment IDs, reversals | Data-quality issue or unresolved payment |
| High rate means false billing | Case mix, size, suppression, period | Comparable numerator/denominator and rules | Outlier only or invalid comparison |
| Revised number means new cash | Reclassification/report correction | Same-date versions and transaction reconciliation | Published revision only |
| Missing record means concealment | Access/coverage/lag/search limit | Bounded source search and disclosure limits | Not located, not proven nonexistent |
| Audit receivable means unpaid fraud loss | Accounting correction, dispute, later credit | Original transaction and recovery/disposition evidence | Receivable fact only |

## Challenge record

For each claim preserve observed fact; inference; source/locator; strongest alternative; test and query boundaries; contrary source/locator; result; revised claim; confidence basis; decisive remaining gap. Do not hide contrary evidence in an unlinked appendix.

## Corroboration

Ask whether evidence is independent in origin and mechanism. Two summaries copying one release add no independent factual confirmation. A bank/payment record and an independently published approval may speak to different edges; neither automatically proves delivery or intent. Keep those scopes explicit.

## Search balance

Use exact identifiers and dates for both supporting and opposing queries. A vague search for exoneration versus targeted searches for misconduct is not a balanced test. Avoid making the absence of an inaccessible private record count against a subject. A non-result can mean the question is not observable from approved sources.

## Synthetic example

A provider appears in two datasets with different names. Before alleging disguise, check former name, DBA, transfer and source dates. If a dated filing explains the change, narrow the finding to a documented name change. If no linking ID exists, keep identity unresolved rather than asserting evasion.
