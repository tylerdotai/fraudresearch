# Stage gates, status and recovery

| Stage | Required artifact | Advance only when | Stop/recover when |
|---|---|---|---|
| Intake | Campaign brief | Question/program/population/period explicit | User request changes or scope ambiguous |
| Program fit | Rule snapshot and applicability note | Relevant program identified or uncertainty retained | Social-media claim substituted for terms |
| Sources | Source contracts, originals, schema | Data can observe the chosen question | Missing denominator, restricted data, unverified coverage |
| Identity | Dated links and candidate register | Identifier namespace and temporal match supported | Name/address only or conflicting ID |
| Analysis | Reproducible commands and outputs | Units, joins, duplicate handling and dates reconciled | Arithmetic/source mismatch, unparsed material rows |
| Challenge | Contrary-evidence matrix | Strongest benign explanations checked | Decisive contradiction invalidates finding |
| Originality | Prior-publication review and analytical delta | New analysis explained without government-knowledge claims | Only an audit/news restatement remains |
| Private report | Claim map, limitations, attachments | Citations/integrity checked; draft blockers visible | Missing or changed evidence |

Use explicit states: proposed, collecting, blocked, analyzed, contradicted, private-draft, ready-for-human-review, closed-no-supported-finding. These are project records, not an automatic workflow engine or Kanban board. `ready-for-human-review` does not mean legally eligible or approved to file.

## Resume

Read the newest campaign checkpoint, the exact user instruction and current source inventory. Do not resume from old memory alone. Verify hashes before reuse; compare source versions without overwriting originals. A changed source requires recalculating affected claims, not quietly substituting the latest figure.

## Partial failure

Keep successful evidence and failed request receipts. Do not label a connector working because its catalog loaded. Log the exact failed URL/status, bounded retry and missing inference. A sign-in screen is not evidence; do not bypass it. Keep a draft with explicit blockers if only part of the chain exists.

## Human handoff

Summarize the strongest supported observation, contrary evidence, unresolved identity/funding/amount links and proposed next action. No contact or submission occurs merely because a report is complete. If action is requested, bind approval to exact recipient, report version, attachments and identity; a changed package requires reconsideration.
