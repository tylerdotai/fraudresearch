# Review Originality

## Purpose and boundary

Assess what this analysis actually adds to known public material. Originality for the written reward rules is not the same as finding an obscure page, producing a new summary or being first in a personal notebook.

## Reference loading

- Before any CLI call in read-only work, or when command effects are uncertain: [Command effects and strict read-only route](../preserve-evidence/references/command-effects.md).
- Before deciding what original means: [Originality tests and exclusions](references/originality-tests.md).
- Before a novelty claim or case handoff: [Prior-publication search and analytical delta](references/prior-publication-search.md).

## Procedure

1. Read originality-tests and the current detailed program definitions. Identify each material proposed allegation and its source lineage before searching for novelty.
2. Follow prior-publication-search using exact entities/identifiers, conduct, project/program and dates. Search original audits, enforcement/court records and reporting; retain actual search boundaries, unavailable sources and publication chronology.
3. Separate copied facts, independently verified facts, new calculations and new supported relationships. Write the analytical delta: which specific non-obvious inference or evidence was added, how it is reproduced, and what alternative explanations survive.
4. Classify the result as restatement, unverified or supported independent analysis. Confidential government knowledge remains unknown even after an extensive public search; a new analysis may still face separate eligibility requirements.
5. Save the review note with exact prior passages and the new evidence chain. Keep disclosure private until an exact authorized decision; do not publish or submit to manufacture a timestamp.

## Completion contract

Every material proposed finding has a prior-publication disposition and an explicit reproducible analytical delta or unresolved label. Restated audits/news are not promoted to original discoveries. No claim is made to know confidential government holdings or to guarantee an award.
