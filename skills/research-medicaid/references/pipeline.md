# Bounded pipeline and private handoff

Use `uv run --project "$HERMES_HOME" fraudlab ...`. Check current `--help` before unfamiliar options. The following are implemented CLI boundaries, not evidence that a Medicaid bulk connector exists.

1. `inspect status`, `inspect sources`, `inspect verify` and `inspect records SOURCE_ID` open an existing case SQLite database read-only and do not initialize a missing home. Legacy status/verify commands still use the older initialization path.
2. `web-search QUERY` uses your configured loopback SearXNG. `web-extract URL` preserves original official .gov response and separately hashed Crawl4AI-rendered text/response for HTML; PDFs use existing pdftotext with retained page breaks and fail explicitly on scan-only content requiring OCR. No CAPTCHA bypass or authenticated browser sessions. Browser subresource egress is not a hardened sandbox. These operations are not substitutes for bulk-data acquisition. Start a fresh Hermes chat after installing or changing a provider plugin.
3. `bulk acquire URL --max-bytes N` streams a credential-free public .gov source under explicit byte/time/disk budgets. `bulk ingest PATH --url URL --max-bytes N` preserves an authorized local original. Never import fixtures into production. Failed/partial transfers are not acquired sources. Resume is deliberately not implemented: retain the failed receipt and use a bounded fresh acquisition rather than append without validators.
4. `bulk convert RAW_ID --required COLUMN --max-rows N --max-expanded-bytes N` validates CSV structure with strict decoding, hashes members and writes Parquet. ZIP inputs also require exact `--member NAME`. `--encoding` is explicit; reversible Latin-1 structural decoding is not validated natural-language name decoding. Source columns stay strings, with one-based `__source_row` for parsed-record references. Never infer row counts from file lines when quoted multiline fields exist.
5. `bulk query DATASET_ID --column COLUMN --equals VALUE --limit N`, `bulk join LEFT_ID RIGHT_ID --left-key COLUMN --right-key COLUMN --limit N` and `bulk verify` verify underlying hashes and do not append analytical events. Join pairs can be many-to-many; namespace, identifier validity, dates and cardinality still require analyst evidence. No arbitrary SQL or automatic DuckDB extensions/network reads are exposed.
6. `bulk connector` currently covers catalog-discovered CMS hospice CHOW, owners, enrollments/additional NPIs, OIG current LEIE and latest reinstatement supplement. Their coverage is not Medicare payment evidence or complete historical exclusion continuity. HHS Medicaid files still require a separately reviewed bounded acquisition and schema contract.

Record the exact returned IDs and commands rather than substituting hypothetical IDs. Keep original, intermediate and report layers separate. Use private incomplete reports with source/member/row locators and a missing-evidence list; schema/integrity passes never establish crimes or award eligibility. Before submitting anything, obtain separate exact approval for recipient, content, attachments and identity.
